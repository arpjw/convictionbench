# convictionbench.org

Project site for **ConvictionBench**: do language models change their answers for good reasons, and only for good reasons?

* Site: https://convictionbench.org
* Code, data generator and results: https://github.com/arpjw/conviction
* Dataset: https://huggingface.co/datasets/arpjw/ConvictionBench

`data.json` is generated from the results by `scripts/export_site.py` in the code repository; do not edit it by hand.

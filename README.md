# convictionbench.org

Project site for **ConvictionBench**: do language models change their answers for good reasons, and only for good reasons?

* Site: https://convictionbench.org
* Paper, Laplace Research edition: https://convictionbench.org/paper.pdf (mirror of the [Laplace Research PDF](https://laplaceresearch.org/convictionbench/paper.pdf))
* Code, data generator and results: https://github.com/Laplace-AI-Research/conviction
* Dataset: https://huggingface.co/datasets/Laplace-AI-Research/ConvictionBench

`data.json` is generated from the results by `scripts/export_site.py` in the code repository; do not edit it by hand.
